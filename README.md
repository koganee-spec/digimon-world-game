# デジタルワールド：育成の旅 v0.2

Three.jsを使ったスマホ向け3D育成ゲーム試作です。

## スマホで遊ぶ方法
1. GitHubでリポジトリを作り、`index.html` をアップロードします。
2. Settings → Pages → Deploy from a branch → `main` / `/(root)` を選んで保存します。
3. 数分後、表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` をスマホのChromeで開きます。
4. Three.jsをCDNから読み込むため、インターネット接続が必要です。

HTMLを直接開くと、ブラウザによってはES Modulesの制限で動かないことがあります。HTTPS公開を推奨します。

## 操作
- スマホ：画面下の矢印で移動。右下のボタンで育成やバトル。
- PC：矢印キーまたはWASDで移動。
- メニュー：セーブ・ロード（同じブラウザ内の保存）。

## 実装済み
- Three.jsによるリアルタイム3Dフィールド、追従カメラ
- ローポリ風のオリジナルモンスター、木、遺跡、看板
- 食事、トレーニング、休息、ほめる、叱る、簡易バトル
- 日数、能力、空腹、疲労、進化分岐、ローカルセーブ
